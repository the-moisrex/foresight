Detailed Description

template<MomentumPolicy Policy>
struct fs8::basic_momentum< Policy >

Generic momentum pipeline mod, parameterized on a Policy.

Tracks the velocity of scroll events and schedules momentum events via the scheduler mod to add inertial scrolling. The policy defines what to track, what to emit, and how to transform events.

Example
// Scroll momentum:
auto pipeline = context
| io_manager
| input_manager
| intercept[keyboard, mouse]
| scheduler
| momentum_scroll
| output;
