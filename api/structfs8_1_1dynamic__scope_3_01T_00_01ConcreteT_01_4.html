Detailed Description

template<polymorphic_scoped T, typename ConcreteT>
requires std::constructible_from<typename T::template model_type<ConcreteT>, ConcreteT*>
struct fs8::dynamic_scope< T, ConcreteT >

Polymorphic version of dynamic scope. If T is polymorphic, then we scope must scope its model; a model will take a pointer to ConcreteT type instead of us, and we will hold the model instead.

The model is a gateway to calling multiple types that implement the same concept but they're not related. The interface is the things that the model must support.
