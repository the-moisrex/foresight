Detailed Description

Scroll momentum pipeline mod.

Tracks the velocity of scroll events and schedules momentum events via the scheduler mod to add inertial scrolling. Emits REL_WHEEL_HI_RES / REL_HWHEEL_HI_RES events with legacy fallback.

Set max_mouse_distance to enable distance-based slowdown on mouse moves.

Example
auto pipeline = context
| io_manager
| input_manager
| intercept[keyboard, mouse]
| scheduler
| momentum_scroll
| output;
