Process and match, but only within a time window. If more than max_gap passes between two relevant key events, the in-progress partial match is dropped (so a pattern whose characters are typed too slowly will never match). last_time holds the time of the last relevant key event; pass the same variable across calls and keep it zero-initialized initially.
