Detailed Description

template<typename T>
struct fs8::is_range_adaptor_closure< T >

True when T derives from std::ranges::range_adaptor_closure<D> for some D (e.g. find_devices, to_queries). Those are piped through the standard views pipe operator, not through the query-tag pipe.
