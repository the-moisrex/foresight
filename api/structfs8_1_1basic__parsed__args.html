Detailed Description

template<std::size_t MaxPositionals, std::size_t MaxFlags, std::size_t MaxNames>
struct fs8::basic_parsed_args< MaxPositionals, MaxFlags, MaxNames >

Result of parsing argc/argv through basic_arguments.

The positional arguments are copied into inline storage (as argv pointers, which outlive main) so flags can be interspersed freely. The object itself is a range over those positionals, so it can be piped through query tags directly, e.g. parsed | grab | required.
