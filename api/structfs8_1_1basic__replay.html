Detailed Description

template<capture_format FormatT = capture_binary_format>
struct fs8::basic_replay< FormatT >

Pipeline mod that reads captured events from a file and injects them into the pipeline on each load_event tag. When the file is exhausted, returns exit.

Auto-detects file format (binary or evtest text) from the file header.

Pipeline form:

auto pipeline = context | stopper | replay | output;
pipeline.mod(replay).set_file("capture-2026-09-04.bin");
pipeline();
