Detailed Description

A lifecycle event (tag replacement) that shares the same field layout as event_type so mods can handle both regular events and lifecycle events in a single overload if desired. The type field is set to EV_MAX + 1 (a value no real kernel event will ever use) so callers can distinguish lifecycle events from real input events.
