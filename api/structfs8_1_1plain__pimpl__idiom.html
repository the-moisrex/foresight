Detailed Description

template<typename>
struct fs8::plain_pimpl_idiom< typename >

A runtime-friendly variant of pimpl_idiom for classes that don't need the consteval-only-copyable restriction (non-mod classes such as runners and services). It can be default-constructed, copied, and moved at runtime; copying deep-clones the impl through nullable_indirect. Derived classes are free to delete copying (e.g. for resources like pipes), and should define template<> struct fs8::plain_pimpl_idiom<Derived>::impl in the implementation TU.
