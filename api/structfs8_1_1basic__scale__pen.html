Detailed Description

Scale pen (absolute) movement events by a factor.

Computes deltas between consecutive ABS_X / ABS_Y values, scales them by factor, and writes back previous + scaled_delta. Place this before abs2rel so the scaled deltas are converted to relative movements downstream.

State is reset on tool-change events (BTN_TOOL_*) so a new stroke starts fresh.

Example
| scale_pen[0.5f] // halve pen movements
| abs2rel
| pen2mice
