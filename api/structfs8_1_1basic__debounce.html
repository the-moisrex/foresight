Detailed Description

template<std::size_t N>
struct fs8::basic_debounce< N >

Debounce events: drop events that arrive too soon after a previous event of the same code. Used to clean up faulty hardware — double-clicking mice, bouncing keyboard switches, noisy axes or scroll wheels.

In click mode (default) a press that lands within time_threshold of the previous press of the same code is dropped together with its matching release, so the key/button state stays consistent. For non-EV_KEY codes click mode degrades to event mode (there is no press/release pair).

In event mode every event of a tracked code arriving within the window of the previous one is dropped, regardless of value.
