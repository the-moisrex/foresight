Detailed Description

Non-template base class that owns the velocity trackers, animation calculators, and all non-template-dependent logic. Defined out-of-line in the .cxx so the pimpl impl stays hidden.

basic_momentum<Policy> inherits from this, adding only the policy-provided constants and the template operator().
