Detailed Description

A struct that wraps an unsigned 32-bit integer representing a state using bit-fields.

The state combines an index (24 bits) and a generation counter (8 bits). This allows checking if a state is still valid by comparing generations, useful for detecting invalidations in structures like vectors where elements may be moved or removed.
