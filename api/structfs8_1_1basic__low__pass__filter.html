Detailed Description

Low-pass filter for mouse movement.

Smooths each frame's movement (dx, dy) with an exponential moving average: 

smoothed = α × newInput + (1 − α) × previousSmoothed

A smaller α smooths more (keeps more history), a larger α tracks the raw input closer. α is clamped to (0, 1]. The first movement frame passes through at full strength, and frames with no movement emit nothing (no residual drift).

Example
... | mouse_history | low_pass_filter | output
... | mouse_history | low_pass_filter[0.4f] | output
