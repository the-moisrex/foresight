Detailed Description

template<std::size_t DefaultsN, std::size_t MaxPositionals = 16, std::size_t MaxFlags = 8, std::size_t MaxNames = 16>
struct fs8::basic_arguments< DefaultsN, MaxPositionals, MaxFlags, MaxNames >

Command-line configuration for an app: default positionals, positional placeholder names (for help), extra flags, and an optional custom help text. Configure it through method chaining (e.g. arguments["x"].help("...").add_flag(...)) and parse with operator()(argc, argv).
