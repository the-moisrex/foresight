Detailed Description

Timer-based event scheduler.

Uses timerfd registered with io_manager to emit events on a configurable periodic interval. Events are queued and drained as a next_event provider — the same pattern as intercept.

Supports:

  • schedule(events) — arm the timer and queue events
  • cancel() — disarm the timer and clear the queue
  • has_pending() — whether events are queued
