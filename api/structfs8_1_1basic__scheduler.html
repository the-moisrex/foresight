Detailed Description

Timer-based event scheduler.

Uses timerfd registered with io_manager to drive tick callbacks. Each tick callback produces a span of events and a timeout for the next invocation.

The scheduler does NOT buffer events itself — it calls the callback when a tick is due and emits the returned events immediately. If the callback returns multiple events, the scheduler stores the remaining span until the next next_event call.

Supports:

  • schedule(fn, data, interval) — register a callback, returns handle
  • cancel(handle) — remove a single callback
  • cancel_all() — remove all callbacks
  • has_pending() — whether any callbacks are registered
