Detailed Description

Monitor and manage input devices.

Owns and maintains discovered evdev devices but does not provide input events. intercept is the event provider, integrating evdev readiness with io_manager. Queries are pulled on demand from registered providers, so the manager can re-ask everyone via requery().

◆ own_device()

void basic_input_manager::own_device ( std::string_view  devnode)
exportnoexcept

Record a device node (e.g. "/dev/input/event9") of a uinput device that this process created. Devices are only ever tagged; they are still enumerated and watched like any other device, and events read back from them carry their normal device id. is_owned answers whether a device id belongs to one of ours.
