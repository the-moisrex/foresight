Detailed Description

Convert mouse movement into scroll-wheel events.

A pure transformer: it has no condition of its own. While it's active it swallows mouse movement (REL_X/REL_Y) and re-emits it as scroll events (REL_WHEEL/REL_HWHEEL + high-res variants). Gate it with hold_mod (e.g. hold_mod[KEY_CAPSLOCK, BTN_MIDDLE, mouse_to_scroll]) so it only runs while a scroll modifier key is held.

Accumulates mouse movement internally and quantizes it into scroll notches: legacy events (±1 per notch) are emitted when the accumulated value crosses the step threshold, while hi-res events carry the full non-quantized value.
