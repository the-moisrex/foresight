Detailed Description

template<dynamically_scoped T, typename = void>
struct fs8::dynamic_scope< T, typename >

Non-Thread-Local, Thread-Safe Global Binding.

This uses a single global std::atomic pointer shared by all threads. Operations on this pointer are atomic, preventing data races during swaps/reads.

Warning
Because this is not thread_local, creating an lbg_scope in one thread will change the active instance for ALL threads. This is intended for "Global Mode Switching" or "Singleton Hot-Swapping", not for per-request contexts. RAII guard to create a new Locally-Bound-Global scope.

Overrides the current binding for T with the provided instance, and restores the previous binding upon destruction. This forms a LIFO stack of contexts.

{
context_type ctx2;
dynamic_scope scope{context, ctx2};
// now `context` is pointing to `ctx2` until `scope` goes out of scope
}

Warning
Because restoration happens in the destructor, instances of dynamic_scope MUST be strictly scoped on the stack. Interleaving lifetimes or passing these across asynchronous boundaries without careful LIFO guarantees will corrupt the binding state.
