Detailed Description

Scroll momentum policy: tracks scroll wheel events (REL_WHEEL_HI_RES/REL_HWHEEL_HI_RES) and emits them during the momentum animation to add inertial scrolling.

Requires scheduler earlier in the pipeline to emit timed events.
