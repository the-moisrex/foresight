Detailed Description

template<idle_repeat::pattern RepeatT = idle_repeat::once>
struct fs8::basic_idle_detector< RepeatT >

Detect pipeline idle (no input events for a configurable period) and broadcast an idle special event to all mods.

Relies on io_manager for the actual poll timeout. The idle event's .value carries the idle duration in microseconds so downstream mods can decide their own thresholds.

Pipeline form:

auto pipeline = context | io_manager | idle_detector | ...;
// or with a repeat pattern:
auto pipeline = context | io_manager
| idle_detector[std::chrono::seconds{1}, idle_repeat::consistent<500'000>>
| ...;
